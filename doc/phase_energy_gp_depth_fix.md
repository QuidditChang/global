# 相变能量 Gauss 点深度修复

日期：2026-09-17。源码分支：`cmbhf_ALA_strict`，基线 `324ecda15d06bc2f3bd4af50f12782cf97a2e780`。

本次只修复相变能量的几何调用错误。按用户明确要求，含相变跳跃的参考密度以及现有 beta、参考态、相变密度和浮力约定均保持不变；此前把参考态约定列为本次待修改问题的建议不执行。

## 错误来源

`lib/Size_does_matter.c::form_rtf_bc()` 将 Cartesian Gauss 点坐标转换为球坐标相关因子：

```c
rtf[3][k] = 1.0/sqrt(x[1]*x[1]+x[2]*x[2]+x[3]*x[3]);
```

因此 `rtf[3]` 是 **1/r**。这是球坐标梯度中的合法几何因子，不能修改这个生产者，也不能把整个 `rtf` 数组统一解释为半径。

`lib/Advection_diffusion.c::element_residual()` 原本将

```c
E->sphere.ro-rtf[3][i]
```

传给 `phase_change_state()` 的 `depth` 参数。正确的无量纲深度应为 `ro-r`，因此调用已改为：

```c
E->sphere.ro-1.0/rtf[3][i]
```

此处使用实际 Cartesian GP 的模长，不额外用节点半径插值替代几何位置；外边界半径仍取 `E->sphere.ro`。

## 为什么影响潜热

共享相变函数采用

\[
q=(z-z_{tr})\,\rho g-\Gamma(T-T_{tr}),\qquad
X=\tfrac12[1+\tanh(q/w)] .
\]

其局部导数为

\[
L=\frac{2X(1-X)}{w},\quad
X_T=-L\Gamma,\quad
X_{r,P}=L[-\rho g+(z-z_{tr})\partial_r(\rho g)] .
\]

能量残差中的相变项是

\[
Q_{phase}=\rho(T+T_{surface})\Delta s
\left[X_T\frac{DT}{Dt}+X_{r,P}u_r\right].
\]

这里 `DT/Dt` 包含局部时间变化及温度平流。修复仅改变传入的 z；单熵项、导数公式、温度来源、符号及残差中的位置均未改变。该项位于热方程残差左侧，对应净加热诊断中减去 `heating_phase`。

在 `ro=1` 的壳内，旧深度 `1-1/r` 为负。以当前尺度 R0=6371 km、在三个名义相变中心取 T=Ttr 为例：

| 真实深度 km | 旧调用深度 km | 旧/正确局部化因子 L |
|---:|---:|---:|
| 410 | -438.199966 | 2.73e-9 |
| 520 | -566.214322 | 1.12e-12 |
| 660 | -736.273857 | 7.24e-18 |

表中比例用当前参考表插值的 rho*g、当前 width=0.01 计算，表示名义中心处的局部导数抑制，不是整个模型的积分热量误差。正确中心 X=0.5；旧调用把 X 推向接近零的饱和区，使两种导数都严重减小。有限精度下部分值直接舍入为零。

节点相变调用使用 `ro-E->sx[...][3][node]`，节点字段本身存储 r，因此节点相变位置没有同样的错误。旧实现会出现节点浮力中的相变存在，但 GP 潜热响应被错误抑制的现象。
