# P8a: shared tracer composition and conductivity

Implemented 2026-10-07 on cmbhf_EBA_PICES; local gates PASS, awaiting HPC audit.
This is not the full 384-rank production configuration. The confirmed eventual
start remains fresh at 249.9 Ma; no PG checkpoint conversion is introduced.

## Implementation

- One tracer population. Flavor stays in extraq[0], Tp in its registered slot.
  Existing predictor/corrector and MPI packing transport both attributes.
- Split the existing tracer lifecycle into shared move and composition-update
  functions. PG still calls them in its original order. PICES calls each once;
  the obsolete mutable moving flag is removed.
- PICES moves using the accepted velocity, views the arrival clock to refresh
  age forcing/reclassify once, then reconstructs ratio composition before the
  thermal stages. TA subsequently uses that same arrival time. Only completion
  commits the clock. Existing material and source formulas are reused.
- Enable EBA ratio composition, chemical buoyancy and kC(Cprim). No new
  conductivity formula: thermal_transport_at_gp remains authoritative.
  Geological reclassification currently requires the target 25-flavor layout,
  primordial flavor24 and P4 age forcing. It preserves primordial identity and
  does not change Tp. Reserved flavors18/19 are not generated by these rules.
- Capability state is established while parsing composition inputs, rather
  than as a side effect of printing instructions. This permits early checks.
- Restoring tracers now only rebuilds counts; it does not reapply geology.
  Composition checkpoint schema3 includes the existing composition payload,
  strict preflight size/schema checks, accepted trench_visit_age and persistent
  new_flag_depth. New-trench history starts defined at zero before its first
  event. Configuration fingerprints include component count, ratio scheme,
  chemical buoyancy, reclassification, primordial identity and buoyancy ratios;
  kC was already fingerprinted. State checksums cover the saved history.
- Runtime checks reject empty composition cells and inconsistent ratios.
  Checkpoint support here still requires P4 and uniform constant viscosity.

## Validation

The five exact input cases are continuous(6), split(2), restart(2→6), kC=1
control and zero chemical-buoyancy control. Synthetic n5, 12 ranks, 128 particles
per element, dt=2.5e-8, start age 2.1 Ma. Production flavor and buoyancy vectors
are copied with whitespace normalized for the standalone parser. This small
mesh validates coupling, not the production resolution or exact basal volume.

- 98,304 particles conserved; primordial count 4,739 unchanged. Background
  flavor histogram changes, demonstrating active reclassification.
- Geological visit ages at checkpoints 0/2/4/6: 3/2/1/1; continuation crosses
  the integer-age update after the split. Continuous/restart states match.
- 480 decoded field outputs and binary live state match. TA/CBF separately
  audited by the existing independent face-integration/heat-ledger verifier.
- Conductivity control changes final temperature RMS by 0.0002206 K; removing
  chemical buoyancy changes it by 3.49305 K. These show active coupling, not
  analytic accuracy or production acceptance tolerances.
- Changed kC or buoyancy ratios are rejected at restart before advancement.
- Original uncomposed P4 continuous/restart regression passes (216 decoded
  fields plus live state). PG two-step composition results before/after the
  refactor match in all 180 decoded outputs, using the prior P7 release binary.
- The real LSF projection gates and gzip restart comparisons pass on local
  outputs. Python/shell syntax and git diff --check pass.

See P8A_LOCAL_RESULT.json for metrics, provenance and TA/CBF residuals.
Local MPI requires permission to open process communication sockets.
