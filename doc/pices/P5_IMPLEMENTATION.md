# P5：PG/PICES 可行性对照

2026-10-02。P4 HPC 作业 12252234 审计通过后实施。P5 提供显式、可重复的
46 个实验配置、共同诊断和审计工具；不自动批准切换生产模型。

## 范围与配置

`p5_case=off` 为默认值。standalone 的 `cold|hot|assim` 模式才启用实验初始化、
计时和诊断。实验要求 12 个球面 cap、每 rank 一个 cap、全新运行、PICES 检查点关闭，
拒绝 restart 与严格 ALA。此阶段仍用 Newtonian 均匀黏度、无组分反馈、无补粒子。
所有实验关闭相变密度及熵跳，不能替代 P3 的相变验证。

输入由 `tests/pices/prepare_p5.py RUNS_PATH` 从 P4 参数确定性生成，存于 runs
的 `pices_p5/`。每个场景有 PG 5 例、PICES 9 例，共 42 例；另有冷、热异常
各一组 PG/PICES 真实 Stokes 对照，共 46 例。每例 12 ranks，LSF 串行执行。

| 维度 | 配置 |
|---|---|
| 网格 | 每 cap 每方向 5 / 9 / 13 节点 |
| 粒子 | 每单元 16 / 32 / 64；PG 不使用粒子 |
| 时间加密 | dt / dt/2 / dt/4，同组终止物理时间相同，4 / 8 / 16 步 |
| Le 敏感性 | 默认 min-directional-RMS 的 0.5 / 1 / 2 倍 |
| 冷、热指定速度 | dt=1e-6，终止 4e-6，绕 z 轴 omega=4000 |
| 全球同化与流动 | dt=1e-7，终止 4e-7，真实 Stokes |
| 冷、热真实流动补充 | dt=1e-8，终止 4e-8，独立于指定速度实验 |

冷异常中心 (0.82,0,0)，热异常中心 (0.68,0,0)，幅度 -/+0.15，Gaussian
尺度 0.12，以径向 sin² taper 消去边界异常，叠加线性背景 (1-r)/0.45。
指定速度 Vphi=omega*r*sin(theta)、Vtheta=Vr=0；关闭 Q0、Di、TA，保留扩散。
无量纲温度转 K 为 300+3400*T，内外边界分别为 3700 K / 300 K。

同化组沿用 P4 的 Tref/HSC 初始化、合成板龄和 relaxed TA，叠加
0.01*sin²(pi*(r-ri)/(ro-ri))*sin²(theta)*cos(2phi) 的共同扰动。
rho=1.1→1、Cp=1.2→1、k prefactor=4/4.8、kT exponent=0.3、Q0=0.3、Di=0.1。
四个整数板龄文件为 30/40/50/60 Ma；空海沟数据不代表真实板块重建。

## 实现约束

- `Pices_benchmark.c` 在粒子建立前设置同一初始网格温度；PG/PICES 输出逐节点核对。
- 指定速度仅在显式实验中跳过 Stokes。真实流动的两种热方法统一使用 P3 的
  RHS-relative 内层容差与失败保护，避免 PG 的旧内层停止条件污染 A/B 对照。
  耦合算例显式设置 `vlowstep=1000`：热异常 PG 的内层求解曾触及默认 250 次上限；
  增加预算但保留 1e-6 RHS-relative 容差和失败保护，外层仍为 500 次。
  因而 PG 实验也输出 `PICES_STOKES`；普通 PG 的容差策略不变。
- `p5_length_scale` 只缩放热交换 Le，保留几何最短边与粒子 CFL 定义。
  仅显式实验可用非 1 值，方法标记为 `min_directional_rms_scaled_v1`。
  实验禁止 PICES 检查点与任何续算，因此不改变已有重启方法或指纹协议。
  PG 仍可能写出旧流程的初始检查点，该文件不用于 P5 续算。
- 所有参数默认关闭时保持旧计算顺序与算式。已有 P4 回归用于验证隔离性。

## 诊断与审计

`P5_METRIC` 每个接受步记录体积积分、rho*Cp*T 能量代理、异常 L1/L2、正异常
质量/质心/均方根半径、峰值/反号峰值、vrms、旋转初场 L2、热阶段/Stokes 累计
最大和平均墙钟、各 rank 峰值 RSS 的最大值及全局粒子数。
异常背景使用节点背景的 FE 插值，避免曲面单元几何误差产生虚假全局异常。
冷、热的旋转初场指标也使用节点采样后 FE 插值；它包含扩散影响，不是精确扩散解误差。
同化场的异常形态仅作共同诊断，不能解释成孤立羽流的几何尺度。

`verify_p5.py` 独立读取输出场、粒子、CBF 和日志，检查：

- 46 例清单与实际输入、步数、时间、有限值、绝对温度边界；HPC 构建提交及输入哈希。
- 冷/热初场的解析定义、PG/PICES 初温逐位相同、粒子总数和 CFL。
- 耦合 Stokes 逐步 PASS；TA 每 rank 每接受步恰好一次。
- PICES 网格能量变化=重映射+热储量+TA 储量（本组无相变且 rho*Cp 静态）。
- CBF 原生面权重、符号与单位独立积分，并与 PICES 边界热反力闭合。
- 时间加密相对最细 dt 的场差、网格形状指标、粒子数和 Le 敏感性，以及 A/B 耗时与内存。

PG 的 CBF 为输出时刻 Eulerian 残差；PICES 为 TA 前热区间平均材料残差。
两者时间/导数语义不同，不能直接把通量差定义为方法误差。
能量代理变化含真实加热、边界、TA 和重映射，不能直接称为守恒漂移；
离散账本闭合也不能证明无物理漂移或粒子质量守恒。

## 验证与生产判据

本地代表性验证结果记录在 `P5_LOCAL_RESULT.json`，未运行的耦合加密项目明确列入待 HPC 验证；完整 46 例由 LSF 执行。检查完成性与可行性结论分开：工具 PASS
表示完整性通过，`production_decision=REQUIRES_REVIEW` 明确保留生产判定。
本地输运试验中，PICES 的时间及网格加密指标改善，但粗网格旋转初场 L2 高于 PG；
同化基准首步重映射能量损失也必须单独评估，不能以热账本闭合替代守恒性评价。
不能据此推荐生产替换。实际 HPC 的耗时、内存、振荡、扩散、动力学与漂移仍需联合审计。
这些短程合成实验不覆盖长期粒子退化、真实板块强迫、温度依赖黏度与高分辨率生产模型。

本地最终核查（34/46，完整清单见 JSON）：

- 28 个冷/热指定速度算例和 6 个真实流动基准全部通过独立场/CBF/账本审计。
  最大网格账本残差 1.09e-14。同化首次重映射能量为初始代理的 -1.293626%。
- P5 关闭时，P4 连续/分段重启的 216 份解码场、120 份 CBF 和有效状态一致；
  相对改造前的 180 份场、96 份 CBF 及有效检查点状态也保持逐位一致。
- 11 项 PICES 与 10 项 CBF 单元测试通过；4 项实验参数拒绝保护通过。
- 热异常 PG 修正后最大内层迭代数为 253，确认无需放松原收敛容差。
- 同化场景剩余 12 个 dt/网格/粒子数/Le 加密算例待 HPC 执行；未计为本地通过。
- 最初调试构建有单例 600 s 超时，后续部分加密运行被主动停止；这些结果均未
  混入最终统计。最终 34 例使用同一 O2 可执行文件和最终提交输入。

复现本地构建使用 OpenMPI standalone；与 HPC Intel/Pyre 安装环境不同：

```bash
MPICC=/usr/local/bin/mpicc python3 tests/cbf/build_validation.py --build-dir /tmp/p5-build --optimization O2
python3 tests/pices/run_p5_local.py /tmp/p5-build RUNS_PATH --output /tmp/p5-new-run
python3 tests/pices/verify_p5.py /tmp/p5-new-run --local --summary /tmp/p5-result.json
```

HPC 输入、提交、归档和下载说明见 runs 的 `PICES_P5_HPC.md`。
