# P5 后续：首次投影偏差隔离与候选方案

2026-10-02。17 个冻结算例和 1 个同构建实际单步对照完成。
**已定位当前算子的静态一致性问题；本步骤未修改生产数值算法。**
证据见 `P5_PROJECTION_ISOLATION_RESULT.json`。

## 测试如何隔离

`build_projection_probe.py` 将生产 `Pices.c` 复制到临时构建目录，在同一编译单元
附加测试入口，以便调用真实的静态 `project`、`assemble` 和 `energy`。
测试可执行文件在完成 P5 初态建立之后执行探针，随后 MPI_Finalize 并正常退出。
不调用任何时间步、粒子移动、热求解、源项更新、TA 更新或 Stokes 求解；速度置零。
同化初态仍保留原始 Tref/HSC 初始化，不通过关闭初始化来更换待测温度场。
生产 `lib/Pices.c`、驱动及已有可执行构建流程均未改动。

冷/热/同化分别测试 5/9/13 节点及 16/32/64 粒子每单元（其余固定，共 15 例），
另加常数和 Cartesian 线性温度场控制。控制场同时使用其自身的固定节点值，
只检验投影性质，不冒充原有 300/3700 K 物理边界问题的解。

探针输出节点、固定掩码、单元贡献累加的局部容量、粒子 Tp、节点关联和插值权重。
Python 按 Cartesian 坐标合并共享节点，独立重建 Q、P 和 FE 能量积分；每个单元
只计算一次，避免重复计数 cap 共享节点。所有例的独立 Q/P 最大差分别为
3.33e-16 / 2.22e-15。常数场保持到舍入误差，所有粒子数量正确。

## 定量结果

以下为本地 9 节点、32 粒子每单元基准的能量代理变化，均相对初始积分归一：

| 初场 | 原始 P(Q(T)) 变化 | 回填固定边界的贡献 | 最终净变化 | 节点最大变化 K |
|---|---:|---:|---:|---:|
| 冷异常 | +0.802675% | -0.715415% | +0.087260% | 152.425 |
| 热异常 | +0.798299% | -0.715180% | +0.083119% | 102.441 |
| 同化初态 | +0.695729% | -1.989104% | -1.293375% | 296.249 |
| 常数 | 0 | 0 | 0 | 7.55e-13 |
| Cartesian 线性 | -0.000070% | +0.000335% | +0.000265% | 19.657 |

固定节点仅在内外径向边界，没有内部固定节点。边界回填保证物理 Dirichlet 条件，
不能为了减小积分差而取消。线性场的全局积分差很小，却有约 19.7 K 局部变化，
说明只看一个全局能量值会漏掉场形状误差。
同化冻结实验的 5/9/13 节点净变化为 -2.315024% / -1.293375% / -0.911379%；
增加空间分辨率能减小全局偏差，但最大局部变化没有对应的单调下降保证。

同一构建另跑原始 `CitcomSFull` 的 P5 同化第 1 步，初始粒子温度全部在
`%.5e` 输出精度内吻合（最大原值与输出的舍入差约 5e-7 无量纲）；初始能量一致。
完整单步 remap 为 -1.293626%，冻结值为 -1.293375%，差为 -0.000251727 个百分点。
冻结/完整 remap 幅值比为 99.9805%。这是同构建数量级对照，不是将耦合效应
精确线性分解为因果百分比；但已证实无需任何动态过程就会出现几乎全部首步偏差。
HPC 的 -1.327855% 与本地值不完全相同，本报告没有把跨平台结果当作逐位相同。

## 根因

设 W 为节点到粒子的插值矩阵，当前 Q(T)=WT。现有返回映射为

```
P(Tp) = D^(-1) W^T Tp,   D = diag(W^T 1)
P(Q(T)) = D^(-1) W^T W T
```

D 是归一化权重和，不等于 W^T W。当前 P 能保持常数，但一般不能还原任意
FE 初场，甚至不精确保持 Cartesian 线性场。边界回填又对投影后的场施加局部修正。
独立重建和 C 完全吻合，因此这是当前算子设计的平滑/一致性性质，不是 C 实现
偏离了该公式，也不是本次试验中的 MPI 丢粒子、TA 重复调用或扩散造成的。

## 候选方案筛选

离线先测试带固定边界的一致最小二乘投影：

```
min_g  1/2 ||W g - Tp||^2,   g_B = T_B
```

对 17 个来自 FE 网格的冻结输入，该候选恢复初场；最大温度误差不超过 9.34e-8 K。
但对粒子温度只取 0/1 的合成径向阶跃，一致投影产生
`g_min=-0.275827`、`g_max=1.343303`，对应约 -637.8 K / 4867.2 K。
**不能把现有 P 直接替换成这个无界线性求解器。**

追加全局上下界的凸二次规划 `0 <= g <= 1`，在同一个阶跃试验中保持
300–3700 K。L-BFGS-B 21 次迭代，投影梯度无穷范数约 1.41e-6。
它证明该反例可以通过受约束投影避免，但尚未证明局部单调性、实际运动下的误差、
并行代价或物理能量守恒。三种离线映射的 FE 能量也不同，不能把“有界”误称为“守恒”。
离线矩阵在单进程上汇总，求解计时不包括生产 MPI 执行，不能用于估计 HPC 成本。

## 建议的下一项改造约束

选择**有界一致的绝对温度投影**作为下一候选方向，先保留显式开关进行回归：

1. 保持同一 FE 初场的静态往返一致性、物理径向边界和允许温度范围。
2. 绝对温度与有符号增量必须区分。现有 P 还用于 subgrid 和 TA 增量；不能
   把绝对温度上下界直接施加到这些增量，也不能默认非线性投影仍满足原线性推导。
3. 为粒子移动、边界、热过程和 TA 分别核算账本。rho*Cp 随空间变化时，不能
   强制每个平流步都维持旧的全局 rho*Cp*T 积分，更不能用整体温度平移掩盖偏差。
4. 先实现并行矩阵作用与失败保护，再完成冻结场、阶跃界限、移动粒子、热子步、
   TA、重启和 P5 全矩阵验证。通过前保留现有生产选择。

本步骤完成的是隔离诊断与候选筛选，不是生产投影修正或新一轮 HPC 方法验收。

## 复现

需要 Python 3、NumPy、SciPy 及本地 MPI。此次版本为 NumPy 2.2.6、SciPy 1.15.3，
Apple clang 21 / OpenMPI 5.0.9，12 ranks，O2。原始探针文件为本机 native float64。

```bash
MPICC=/usr/local/bin/mpicc python3 tests/cbf/build_validation.py --build-dir /tmp/projection-build --optimization O2
python3 tests/pices/build_projection_probe.py /tmp/projection-build
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 tests/pices/run_projection_probe.py /tmp/projection-build RUNS_PATH --output /tmp/projection-new
```

结果目录必须为新目录，工具会拒绝覆盖旧试验。构建的是独立测试可执行文件，
没有新增 HPC 提交包装器，也不需要为此原样重投 P5。
